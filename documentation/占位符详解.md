# 占位符详解

本文档说明 Stellar Theme 中所有"模板字符串 / 占位符 / 数据单位"类约定，方便运营配置时准确替换。

---

## 一、头像模板占位符（`avatar_source`）

`env.js` 中的 `avatar_source` 是一个 URL 模板，支持三个占位符，用于为没有头像的用户生成统一头像。

```js
avatar_source: 'https://api.dicebear.com/9.x/initials/svg?seed={email}',
```

| 占位符 | 含义 | 取值优先级 |
| --- | --- | --- |
| `{email}` | 用户邮箱 | `user.email`（空则为空串） |
| `{username}` | 用户名 | `user.username` → `user.name` → 邮箱 `@` 前缀（再空则为空串） |
| `{seed}` | 稳定随机种子 | `user.uuid` → 邮箱 → 用户名 → `'user'` |

**替换规则**（`src/utils/avatar.ts`）：

- 占位符**大小写不敏感**（`{EMAIL}` 同样生效）。
- 替换值会经过 `encodeURIComponent` **URL 编码**，含特殊字符的邮箱可安全拼接进 URL。
- 未配置 `avatar_source` 时，回退使用后端的 `avatar_url` 字段。

**示例**：

```js
// 用户 email = a+b@example.com，uuid = abc-123
avatar_source: 'https://api.dicebear.com/9.x/initials/svg?seed={seed}&email={email}'
// 实际请求：https://api.dicebear.com/9.x/initials/svg?seed=abc-123&email=a%2Bb%40example.com
```

常用免费头像服务（DiceBear）示例：

```js
avatar_source: 'https://api.dicebear.com/9.x/initials/svg?seed={username}'
avatar_source: 'https://api.dicebear.com/9.x/pixel-art/svg?seed={seed}'
avatar_source: 'https://api.dicebear.com/9.x/bottts/svg?seed={seed}'
```

## 二、客服身份注入（`window.customerServiceIdentity`）

开启客服且 `identify_user: true` 时，前端会把**当前登录用户**的身份同步给客服平台。如需覆盖或注入服务端生成的身份（尤其是 **Tawk 安全模式 HMAC**），可在应用启动前（如 `header_code` 中）设置全局对象：

```js
window.customerServiceIdentity = {
  user_id: 'CURRENT_USER_ID',          // 用户 UUID
  hash: 'SERVER_GENERATED_TAWK_HASH',  // 服务端用 Tawk Property API Key 对 user_id 生成的 HMAC SHA256
  name: 'Current User',
  email: 'user@example.com',
  avatar: 'https://example.com/avatar.png',
  attributes: { plan: 'pro' },         // 自定义属性，覆盖 env.js 中的 attributes
}
```

> ⚠️ 安全要求：`hash` 必须由**服务端**为每个用户实时生成，禁止把通用 hash 或 API Key 写入任何前端静态文件（写死即泄露，任何人可伪造客服身份）。

### 前端自动同步的客户档案字段

当未注入 `window.customerServiceIdentity` 时，前端从登录用户信息中自动同步以下属性（白名单，非全部用户数据）：

| 属性 | 来源 |
| --- | --- |
| `email` | 用户邮箱 |
| `registered_at` | 注册时间 |
| `plan_name` | 当前套餐名 |
| `expired_at` | 到期时间 |
| `used_traffic` | 已用流量 |
| `total_traffic` | 总流量 |

`env.js` 中 `customer_service.attributes` 自定义属性会合并进这些字段；`identify_user: false` 可完全关闭身份同步。

### 客服事件与公开 API

页面可监听统一事件（所有提供方均触发）：

```js
window.addEventListener('stellar:customer-service', (event) => {
  console.log(event.detail.provider, event.detail.event, event.detail.payload)
  // 例如 event.detail.event = 'onChatStarted' / 'onChatEnded' / 'onOfflineSubmit' / 'error'
})
```

调用公开 API（加载完成后可用）：

```js
await window.stellarCustomerService?.open()
await window.stellarCustomerService?.hide()
window.stellarCustomerService?.track('order_created', { plan_id: 1 })
```

## 三、双语配置占位

主题内置中英双语（zh-CN / en-US），以下配置字段支持"中文 + 英文"成对填写，英文界面优先取 `_en` 字段，留空回退中文：

| 配置 | 双语字段 |
| --- | --- |
| 落地页导航 | `label` / `label_en` |
| 侧边栏导航 | `label` / `label_en` |
| 落地页 Hero | `badge/badge_en`、`title/title_en`、`title_suffix/title_suffix_en`、`subtitle/subtitle_en`、`features[].label/label_en` |
| 邀请分享文案 | `social_sharing.title` / `description`（单字段，两种语言共用；留空使用内置翻译） |

> 其余 UI 文案全部走 `src/i18n/index.ts` 的 `zh-CN` / `en-US` 消息表，无需配置。

## 四、数据单位约定

主题内所有数值字段遵循固定单位，配置/对接后端时务必注意：

| 数据 | 单位 | 示例 |
| --- | --- | --- |
| 金额（套餐价、余额、佣金、订单金额） | **分** | `2900` = ¥29.00 |
| 套餐总流量 `transfer_enable` | **GB** | `500` = 500 GB |
| 订阅已用/剩余流量 `u` / `d` / `transfer_enable` | **字节** | `536870912` = 512 MB |
| 时间（`created_at` / `expired_at` / `paid_at`） | **秒级时间戳** | `1710000000` |
| 手续费 | 固定值：**分**；百分比：**百分比数字** | `handling_fee_fixed: 50`（¥0.50）、`handling_fee_percent: 1`（1%） |

## 五、关于"没有"的占位符

- **订阅链接 / 邀请链接**：无前端模板占位符。订阅链接（`subscribe_url`）与邀请链接（`invite` 页面生成）由**后端返回**，前端原样展示，主题不拼接。
- **支付回调 / 通知 URL**：由后端与支付网关配置，与前端无关。
- **env.js 环境变量**：静态托管场景（Vercel 等）可用 `STELLAR_` 前缀环境变量在构建时替换 `env.js` 值（见[部署教程](./部署教程.md)），但仅支持已列出的键，不支持新增键。
- **运行时插值**：主题不提供 `{{user.email}}` 之类的内容插值；唯一运行时替换发生在 `avatar_source`（见上文）。
