# 配置文件详解

Stellar Theme 的唯一运行时配置入口是 `public/env.js`（构建后为 `dist/env.js`）。该文件在页面加载时被 `index.html` 读取，生成 `window.settings` 与 `window.routerBase`。**修改后无需重新构建，刷新页面即生效**（注意配置 CDN/Nginx 对该文件禁用缓存）。

> **首次部署**：`public/env.js` 含真实后端地址等运营信息，**已被 git 忽略且不再进版本库**；仓库只提供无敏感值的模板 `public/env.js.example`。首次部署需先执行 `cp public/env.js.example public/env.js` 并填写真实配置；`npm run build` 的 `prebuild` 钩子会在 `env.js` 缺失时自动从模板复制，保证全新 clone 也能构建成功（构建出的仍为模板占位值，部署前务必替换）。

> 配置原则：
> - 只填写需要覆盖的字段，未填写的字段自动使用内置默认值（`src/utils/settings.ts` 中定义）。
> - 值为 JS 字面量：字符串用单引号、数字/布尔原样、数组用 `[]`、对象用 `{}`。
> - 中英文双语字段（如 `label_en`）：英文模式优先取 `label_en`，留空则回退到中文 `label`。
> - **不要**在配置中存放密码、Token、订阅链接等私密信息。

## 一、全局

### `routerBase`

- 类型：`string`，默认 `'/'`
- 前端路由基础路径，必须以 `/` 开头和结尾。
- 根目录部署：`'/'`；子目录部署：`'/stellar/'`。

## 二、品牌信息

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `title` | string | `'Stellar'` | 站点名称（浏览器标题、侧边栏品牌名） |
| `description` | string | `'Stellar Panel'` | 站点简介（仪表盘横幅、登录页副标题） |
| `logo` | string | `''` | 自定义 Logo 地址（URL 或站内路径）；留空使用默认图标 |
| `version` | string | `'1.0.0'` | 前端展示的版本号 |
| `avatar_source` | string | `''` | 用户头像源 URL 模板，支持 `{email}` / `{username}` / `{seed}` 占位符，详见[占位符详解](./占位符详解.md) |

## 三、资源与主题

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `assets_path` | string | `'/assets'` | 静态资源目录，一般保持默认 |
| `theme.color` | string | `'default'` | 主题色标识（`default` / `blue` / `black` / `darkblue`）。**当前版本主色由 CSS 变量 `--stellar-primary` 控制**，该字段为预留标识；如需自定义品牌色，可用 `header_code` 注入 CSS 覆盖 `:root` / `html.dark` 中的 `--stellar-primary` 等变量 |
| `background_url` | string | `''` | **旧版配置**，仅用于认证页背景，已由 `background` 配置取代；两者同时配置时以 `background` 为准 |
| `header_code` | string | `''` | 页头自定义代码，注入 `<head>` 标签尾部；支持 `<script>` / `<style>` / `<link>` / `<meta>` |
| `footer_code` | string | `''` | 页脚自定义代码，在页面底部渲染；可放统计代码、版权信息等 |

## 四、落地页

### `landing_theme_mode`

- 类型：`'dark' | 'light'`，默认 `'dark'`
- 落地页默认主题模式（后台页面仍可手动切换深浅色）。

### `landing_page_enabled`

- 类型：`boolean`，默认 `true`
- `false` 时关闭落地页，访问 `/` 直接跳转登录/仪表盘。

### `landing_hero`

- 类型：`object`，默认全部空
- 官网顶部 Hero 文案，支持中英文双语：

```js
landing_hero: {
  badge: '',          // 徽标（中文）
  badge_en: '',       // 徽标（英文）
  title: '',          // 主标题（中文）
  title_en: '',       // 主标题（英文）
  title_suffix: '',   // 标题后缀（中文，渐变高亮部分）
  title_suffix_en: '',
  subtitle: '',       // 副标题（中文）
  subtitle_en: '',
  features: [         // 卖点列表（勾选样式）
    { label: '稳定高速', label_en: 'Stable and fast' },
  ],
}
```

### `landing_navigation`

- 类型：`object`，默认 `{ items: null }`（null 时显示内置导航）
- 落地页顶部导航。`items: []` 表示隐藏全部链接；`items: null` 表示使用内置导航。

```js
landing_navigation: {
  items: [
    { label: '功能', label_en: 'Features', url: '#features' },          // 锚点
    { label: '套餐', label_en: 'Pricing', url: '#pricing' },
    { label: '状态页', label_en: 'Status', url: 'https://status.example.com', new_tab: true }, // 外链新窗口
  ],
}
```

| 字段 | 说明 |
| --- | --- |
| `label` / `label_en` | 中文 / 英文文案 |
| `url` | 支持 `#锚点`、站内路径（`/dashboard`）、`http(s)://`、`mailto:`、`tel:` 链接；其他协议会被安全过滤丢弃 |
| `new_tab` | 是否新窗口打开 |
| `visible` | `false` 时隐藏该项 |

## 五、后台侧边栏

### `sidebar_navigation`

- 类型：`object`，默认 `{ items: null }`（null 时使用内置菜单）
- `items: []` 隐藏全部菜单项。

```js
sidebar_navigation: {
  items: [
    { label: '仪表盘', label_en: 'Dashboard', path: '/dashboard', icon: 'dashboard' },
    { type: 'group', label: '产品服务', label_en: 'Products' },          // 分组标题
    { label: '购买套餐', label_en: 'Plans', path: '/plans', icon: 'shop' },
    { label: '服务状态', label_en: 'Status', url: 'https://status.example.com', icon: 'world', new_tab: true, badge: 'NEW' },
  ],
}
```

| 字段 | 说明 |
| --- | --- |
| `type` | `'link'`（默认）或 `'group'`（分组标题，仅需 label） |
| `label` / `label_en` | 双语文案 |
| `path` | 站内路径，如 `/dashboard`（会校验是否合法站内目标） |
| `url` | 外链，如 `https://...`（与 `path` 二选一） |
| `icon` | 图标名，见下方图标表 |
| `badge` | 徽标文字，如 `'NEW'` |
| `new_tab` | 外链是否新窗口打开 |
| `visible` | `false` 时隐藏该项 |

**可用图标**（`StellarIcon` 内置，Tabler 风格）：

`dashboard`（仪表盘）、`shop`（购买）、`server`（线路）、`receipt`（订单）、`ticket`（工单）、`users`（邀请）、`chart`（流量）、`book`（文档）、`user`（账户）、`world`、`wifi`、`shield`、`settings`、`lock`、`mail`、`credit`、`crown`、`money`、`link`、`copy`、`qrcode`、`scan`、`send`、`message`、`activity`、`arrowRight`、`arrowUpRight`、`arrowUp`、`file`、`language`、`moon`、`sun`、`menu`、`close`、`router`、`userCircle`、`logout`

**兼容别名**：`grid → dashboard`、`cart → shop`、`chat → ticket`、`people → users`、`stats → chart`、`person → user`、`knowledge → book`、`plans → shop`、`orders → receipt`、`servers → server`、`traffic → chart`、`profile → user`、`invite → users`、`tickets → ticket`

## 七、客户端下载

### `client_downloads`

- 类型：`object`，默认全部 `''`
- 仪表盘"客户端下载"卡片：配置了下载地址的平台才会显示。

```js
client_downloads: {
  windows: 'https://.../clash-verge.exe',
  macos: '',
  android: '',
  ios: '',
  linux: '',
  router: '',
}
```

## 八、一键订阅导入

### `client_imports`

- 类型：`object`

```js
client_imports: {
  enabled: true,   // 是否启用一键导入弹窗（false 时弹窗只显示二维码）
  clients: [],     // 白名单：填写客户端 ID 或名称；留空 = 允许全部
}
```

`clients` 白名单支持**客户端 ID**（如 `'ios-shadowrocket'`）或**客户端名称**（如 `'shadowrocket'`，会匹配所有平台的同名客户端）。

**内置客户端 ID 全表**（平台 → ID）：

| 平台 | 客户端 ID |
| --- | --- |
| iOS | `ios-shadowrocket`、`ios-surge`、`ios-stash`、`ios-quantumultx`、`ios-hiddify`、`ios-singbox`、`ios-loon` |
| Android | `android-flclash`、`android-v2rayng`、`android-clash`、`android-surfboard`、`android-clashmeta`、`android-nekobox`、`android-singbox`、`android-hiddify` |
| Windows | `windows-flclash`、`windows-clashverge`、`windows-clash`、`windows-nekoray`、`windows-singbox`、`windows-hiddify` |
| macOS | `mac-flclash`、`mac-clashverge`、`mac-clashx`、`mac-clashmetax`、`mac-surge`、`mac-stash`、`mac-quantumultx`、`mac-singbox`、`mac-hiddify` |

示例白名单：

```js
client_imports: {
  enabled: true,
  clients: ['ios-shadowrocket', 'android-v2rayng', 'clashverge'],  // 名称 clashverge 会同时匹配 windows/mac 的 Clash Verge
}
```

social_sharing: {

## 十、第三方客服

### `customer_service`

- 类型：`object`，默认 `enabled: false`
- 支持五种提供方：`tawk` / `crisp` / `chatwoot` / `intercom` / `custom`（自定义脚本）。

```js
customer_service: {
  enabled: true,
  provider: 'tawk',

  // 通用配置
  load_delay: 800,          // 延迟加载毫秒数
  load_on_idle: true,       // 页面空闲后再加载
  identify_user: true,      // 是否同步登录用户身份（ID/邮箱/头像/套餐信息）
  track_page_views: true,   // 是否上报页面浏览
  show_on_routes: [],       // 仅这些路由显示；空数组 = 全部路由
  hide_on_routes: ['/login', '/register', '/forget'],  // 这些路由隐藏（优先于 show_on_routes）
  show_on_auth_routes: true,// 登录/注册/找回页是否显示
  hide_on_mobile: false,    // 移动端是否隐藏
  tags: ['stellar'],        // 会话标签
  attributes: {},           // 自定义客户属性（透传给客服平台）
  allow_insecure_http: false, // 是否允许 http 脚本（默认仅 https，localhost 除外）

  // Tawk
  tawk_property_id: '',
  tawk_widget_id: 'default',
  tawk_auto_start: true,
  tawk_secure_hash: '',     // 安全模式 hash，必须由服务端生成，禁止写死通用值
  tawk_custom_style: {},

  // Crisp
  crisp_website_id: '',

  // Chatwoot（支持官方云与自托管）
  chatwoot_base_url: '',
  chatwoot_website_token: '',
  chatwoot_locale: 'auto',
  chatwoot_position: 'right',

  // Intercom
  intercom_app_id: '',
  intercom_api_base: 'https://api-iam.intercom.io',

  // 自定义脚本
  script_url: '',           // 仅接受 HTTPS（localhost 除外）
}
```

**路由规则**：`show_on_routes` / `hide_on_routes` 支持精确路径和结尾通配符（如 `/tickets*` 匹配工单列表及详情页）；`hide_on_routes` 优先级高于 `show_on_routes`。

**身份同步**：`identify_user: true` 时向客服平台同步当前用户的 UUID、邮箱、头像、套餐名、到期时间、已用/总流量等客户档案字段；关闭可避免隐私数据外发。更多见[占位符详解](./占位符详解.md)。

## 十一、全站背景

### `background`

- 类型：`object`，默认 `enabled: false`
- 支持静态图片 / 视频两种媒体类型，固定铺满视口（`position: fixed`），叠加半透明遮罩提升前景可读性。

```js
background: {
  enabled: false,
  type: 'image',            // 'image' | 'video'
  url: '',                  // 媒体地址（图片或视频）
  desktop_url: '',          // 电脑端（视口 > 767px 优先）
  mobile_url: '',           // 手机端（视口 ≤ 767px 优先）
  poster: '',               // 视频封面图（仅 video）
  overlay_opacity: 0.35,    // 遮罩透明度 0-1
  overlay_color: '#000000', // 遮罩颜色
  video_autoplay: true,     // 仅 video
  video_loop: true,         // 仅 video
  video_muted: true,        // 仅 video（自动播放必须静音）
}
```

**回退规则**：`desktop_url` / `mobile_url` 为空时按"另一端 → 通用 `url`"回退，因此只配 `url` 的旧部署无需修改。

## 十二、毛玻璃特效

### `glassmorphism`

- 类型：`object`，默认 `enabled: false`
- 启用后所有 `.stellar-glass` / `.stellar-card` 卡片应用 `backdrop-filter` 毛玻璃效果，由 CSS 变量驱动，运行时调整无需重新构建。

```js
glassmorphism: {
  enabled: false,
  blur: 12,                 // 背景模糊强度 px
  opacity: 0.65,            // 卡片背景透明度 0-1
  border_style: 'light',    // 'none' | 'solid' | 'light'
  border_color: 'rgba(255, 255, 255, 0.18)',
  border_width: 1,
  radius: 12,               // 卡片圆角 px
}
```

## 十三、文档中心

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |

## 十三·一、会话超时

### `session`

- 类型：`object`，默认 `{ idle_hours: 12, max_hours: 24, remembered_max_hours: 24 }`
- 控制登录会话的自动登出策略，单位均为**小时**，`0` 表示不限制。

```js
session: {
  idle_hours: 12,            // 空闲超时：无操作超过该时长自动登出；0 = 不限制
  max_hours: 24,             // 绝对超时上限：登录后超过该时长强制登出；0 = 不限制
  remembered_max_hours: 24,  // 勾选"记住我"时的绝对超时上限；未配置时与 max_hours 相同
}
```

- 不勾选"记住我"的会话（token 存于 sessionStorage）使用 `idle_hours` + `max_hours`；
- 勾选"记住我"的会话（token 存于 localStorage）使用 `idle_hours` + `remembered_max_hours`；
- VPN 订阅用户可能一周才打开一次面板，建议为"记住我"会话配置较大值或 `0`（不自动登出），避免"为什么又要登录"客诉；
- **未配置时行为与修复前完全一致**（12h 空闲 / 24h 绝对）。

## 十三·二、公告标签

### `notice_tags`

- 类型：`object`，默认同时支持中文与英文关键词
- 用于套餐页公告列表（`plan`）、自动弹窗（`popup`）、重要高亮（`important`）。后端公告标签为英文（`Plan` / `Popup` / `Important`）也能正确识别；匹配时对标签做 `trim()` 且不区分大小写。

```js
notice_tags: {
  plan: ['套餐', 'Plan'],       // 出现在该列表的公告标签
  popup: ['弹窗', 'Popup'],     // 会触发自动弹窗的公告标签
  important: ['重要', 'Important'], // 标题高亮为重要的公告标签
}
```

## 十四、后端 API

### `api`

```js
api: {
  // 【模式】'static' 固定地址列表（静态托管推荐，支持多地址+健康检测）；'auto' 同源拼接
  url_mode: 'static',

  // 【static 模式】后端地址列表（可多个，逗号分隔或数组）
  static_base_urls: ['https://panel.example.com'],

  // 【auto 模式】同源拼接规则
  auto: {
    use_same_protocol: true,  // false 时强制 https
    host: '',                 // 留空 = 当前域名
    append_path: '',          // 如 '/api'
  },

  // 【健康检测】多地址时前端自动探测可用后端
  check_enabled: true,
  check_path: '/api/v1/guest/comm/config',

  // 【正向转发】解决 CORS / 内网穿透（非必须不启用；需服务端实现对应转发并配白名单防 SSRF）
  proxy_enabled: false,
  proxy_url: '',
  proxy_path: '/api-proxy',
  proxy_mode: 'base64Path',   // 'base64Path' | 'query' | 'plainPath'

  // 【后端类型】'xboard' | 'v2board' | 'auto'（自动探测）
  backend_type: 'auto',

  // 【支付方式排除名单】按 payment 标识精确匹配，隐藏无法使用/不希望展示的支付方式
  exclude_payment_methods: [],   // 例如 ['StripeCredit']；默认空
}
```

### 模式说明

| 模式 | 适用场景 | 说明 |
| --- | --- | --- |
| `url_mode: 'static'` | 前端与后端不同源 | 直连配置的后端地址；多地址时 `check_enabled: true` 可自动选择可用后端 |
| `url_mode: 'auto'` | 前后端同域 | 按协议+域名+`append_path` 自动拼接 API 地址 |
| `proxy_enabled: true` | CORS 受限 / 内网穿透 | 所有请求经 `proxy_url` 转发，目标地址以 `proxy_mode` 编码（`base64Path` 需服务端配合解码） |

### 后端类型（backend_type）

- `xboard`：cedar2025/Xboard（魔法链接登录、礼品卡完整模块、Turnstile/reCAPTCHA v3 等）
- `v2board`：wyx2685/v2board 及兼容系（工单提现、流量提前重置、解绑 Telegram 等）
- `auto`：首次请求 `guest/comm/config` 后按字段特征自动判断，无法判断时按 Xboard 处理

> 切换后端类型会同时切换 **API 路径表** 与 **能力开关**（如"修改邮箱"、礼物卡模块、流量提前重置按钮的显隐），同一套前端无需改动代码。

## 附：默认值参考

未配置字段的全部默认值定义在 `src/utils/settings.ts` 中，页面运行时通过 `Object.freeze` 冻结 `window.settings`，防止运行中被意外篡改；同时合并过程会过滤 `__proto__` / `constructor` 键，防止原型污染。
