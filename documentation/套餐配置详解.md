# 套餐配置详解

套餐数据由**后端 API 提供**（Xboard 支持游客获取套餐列表，v2board 需登录后获取）。本主题不负责创建套餐，只负责展示与购买流程；以下说明帮助你在**后端管理后台**正确配置套餐，并理解前端如何渲染。

> ⚠️ **数据单位约定（重要）**
> - **金额**：后端所有金额字段单位为**分**（如 `month_price: 2900` 表示 ¥29.00），前端自动 ÷100 展示。
> - **套餐流量**：`transfer_enable` 单位为 **GB**。
> - **订阅流量（已用/剩余）**：`u` / `d` / `transfer_enable` 单位为**字节**，前端自动换算 B/KB/MB/GB/TB。
> - **时间**：`created_at`、`expired_at` 等为**秒级时间戳**。

---

## 一、套餐字段详解

后端返回的套餐对象字段（`src/api/types.ts` 中 `Plan` 类型）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 套餐 ID（路由与下单使用） |
| `name` | string | 套餐名称（展示在卡片、结算页、订单中） |
| `tags` | string[] | 套餐标签 |
| `content` | string | 套餐介绍内容，支持 **JSON / HTML / Markdown** 三种格式，详见下文 |
| `month_price` | number \| null | 月付价格（分） |
| `quarter_price` | number \| null | 季付价格（分） |
| `half_year_price` | number \| null | 半年付价格（分） |
| `year_price` | number \| null | 年付价格（分） |
| `two_year_price` | number \| null | 两年付价格（分） |
| `three_year_price` | number \| null | 三年付价格（分） |
| `onetime_price` | number \| null | 一次性买断价格（分） |
| `reset_price` | number \| null | 流量重置包价格（分）；有值才在仪表盘显示"重置流量"按钮 |
| `capacity_limit` | number \| null | 设备数上限（部分后端） |
| `transfer_enable` | number | 套餐总流量（GB） |
| `speed_limit` | number \| null | 速率限制 |
| `device_limit` | number \| null | 在线设备数限制 |
| `show` | boolean | 是否在前端展示（前端过滤条件之一） |
| `sell` | boolean | 是否可售卖（前端过滤条件之一） |
| `renew` | boolean | 是否允许续费 |
| `reset_traffic_method` | string \| null | 流量重置方式 |
| `sort` | number \| null | 排序权重，升序 |
| `group_id` | number \| null | 套餐分组 |

## 二、价格与周期

### 周期优先级

前端展示"价格 + 周期标签"时按以下优先级取第一个有值的字段：

1. `month_price`（月付）
2. `quarter_price`（季付）
3. `half_year_price`（半年付）
4. `year_price`（年付）
5. `two_year_price`（两年付）
6. `three_year_price`（三年付）
7. `onetime_price`（一次性）

> 例如套餐只有 `year_price`，卡片就展示"¥xxx / 年"；全为空则显示 `-`。

### 套餐页筛选

"购买套餐"页顶部提供筛选：

| 筛选 | 规则 |
| --- | --- |
| 全部 | 所有 `show !== false && sell !== false` 的套餐 |
| 周期 | 存在任一月/季/半年/年付价格 |
| 流量 | `transfer_enable > 0` |
| 一次性 | `onetime_price !== null` |

排序支持：默认（`sort` 升序）、价格升序、价格降序、流量降序。

### 结算页周期与省钱提示

结算页列出套餐**所有有值**的价格字段，并相对月付计算"节省"金额（`月付 × 月数 − 周期价`），节省 > 0 时显示红色"省 ¥xx"标签。

## 三、套餐介绍 content —— 三种格式

`content` 字段由 `src/utils/safe.ts` 的 `renderRichContent` 渲染，判断顺序：**JSON → 纯 HTML → Markdown/混排**，所有路径最终经 DOMPurify 消毒（XSS 安全）。

### 格式一：JSON 结构化（推荐，最整齐）

内容以 `{` 或 `[` 开头且可被 `JSON.parse` 解析时，按结构化渲染。

**最简数组形式**：

```json
["不限速高速线路", "支持多设备同时在线"]
```

**对象 + items 形式**（推荐）：

```json
{
  "title": "套餐亮点",
  "items": [
    "不限速高速线路",
    { "label": "线路数", "value": "50+" },
    { "text": "支持多设备" },
    { "label": "官网", "value": "前往", "link": "https://example.com" },
    { "divider": true },
    { "label": "推荐", "value": "年付立省 20%", "highlight": true }
  ]
}
```

**多分组 sections 形式**：

```json
{
  "sections": [
    { "title": "基础", "items": ["线路 50+", { "label": "速率", "value": "不限速" }] },
    { "title": "高级", "items": ["专线", "独享 IP"] }
  ]
}
```

**条目类型一览**：

| JSON 写法 | 渲染效果 |
| --- | --- |
| `"文本"` 或 `{ "text": "文本" }` | 勾选图标 + 文本条目 |
| `{ "label": "名称", "value": "值" }` | 键值对条目（label 左 / value 右） |
| `{ "label": "名称", "value": "值", "link": "https://..." }` | 键值对 + 外链（新窗口，带 ↗ 图标） |
| `{ "label": "名称", "value": "值", "highlight": true }` | 高亮键值对（强调背景） |
| `{ "divider": true }` | 分隔线 |
| `{ "title": "...", "items": [...] }` | 分组小标题 + 条目列表（`features` 为 `items` 的别名） |
| `{ "sections": [...] }` | 多个分组 |

> 若对象没有 `items` / `features` / `sections`，其余键值对会被自动作为条目渲染（`{ "线路数": "50+" }`）。

### 格式二：纯 HTML

内容以 `<` 开头、含块级 HTML 标签且无明显 Markdown 特征时，直接经 DOMPurify 消毒后输出：

```html
<ul>
  <li>不限速高速线路</li>
  <li>支持多设备同时在线</li>
</ul>
```

> 可用样式类（与 JSON 渲染共用）：`.jt`（分组标题）、`.jt-list`、`.jt-text`、`.ji`（勾选图标）、`.jt-kv`、`.jt-kv.is-hl`（高亮）、`.jt-label`、`.jt-value`、`.jt-divider`、`.jt-link`。

### 格式三：Markdown / 混排

其余情况统一走 `marked` 解析（GFM：表格、删除线、自动换行），HTML 与 Markdown 可混排，最终同样经 DOMPurify 消毒：

```markdown
## 套餐亮点

- 不限速高速线路
- 支持多设备

| 项目 | 说明 |
| --- | --- |
| 线路数 | 50+ |

> 年付立省 20%
```

## 四、购买与结算流程

前端结算为"两步"模型，与 Xboard 后端契约对齐：

1. **创建订单**：结算页选择周期（可选填优惠码）→ `order/save` 创建订单 → 回读订单详情。
2. **确认支付**：订单详情展示**真实抵扣结果**（余额折抵 `balance_amount`、套餐折抵 `surplus_amount`、支付手续费 `handling_fee`），0 元订单直接激活；有金额订单选择支付方式 → `order/checkout` 结算。

支付结果分支：

| 返回 | 行为 |
| --- | --- |
| `type: -1, data: true` | 免费/余额订单已处理完成 → 提示成功并跳转订单页 |
| `type: -1` | 支付失败，展示后端返回的失败原因 |
| `type: 0` | 支付成功 → 跳转订单页 |
| `data` 为 URL | 当前页跳转到支付网关（避免弹窗拦截） |
| `data` 为 HTML 表单 | 自动解析并提交第一个表单（防拦截） |
| 其他 | 以 blob 页打开 |

> 已知限制：**StripeCredit（Stripe 信用卡）在前端不展示**（需要客户端侧 tokenize，当前主题未实现），后端返回该支付方式时结算页会提示"暂不支持信用卡支付"。如需开通信用卡收款，需后端配合扩展。

## 五、优惠券

前端统一处理两种后端的优惠券格式（`src/utils/backend.ts` `normalizeCoupon`）：

| 后端 | 原始格式 | 前端统一 |
| --- | --- | --- |
| Xboard | `type: 'fixed' \| 'percentage'`，百分比 value 为小数（`0.2` = 20%） | 同上 |
| v2board | `type: 1 \| 2`（1=固定，2=百分比），百分比 value 为整数（`20` = 20%） | 统一为字符串 type，value 换算为小数 |

结算页展示"原价 → 优惠券折扣 → 最终价"；下单后以订单详情真实金额为准。

## 六、公告与套餐页

套餐页从公告接口拉取全部公告，按**标签**过滤：

| 标签（中文，硬编码匹配） | 效果 |
| --- | --- |
| `套餐` | 出现在套餐页"公告"列表 |
| `弹窗` | 进入套餐页自动弹窗（可勾选"今日不再显示"，按日期存 localStorage） |
| `重要` | 标题红色高亮 |

> ⚠️ 注意：标签匹配为**中文字符串硬编码**（`src/views/Plans.vue`）。若后端公告使用英文标签，上述功能不会生效，需保持中文标签。

## 七、流量重置

仪表盘"重置流量"入口有两种实现，取决于后端能力：

- **Xboard**：依赖套餐 `reset_price` 字段 → 点击后取消待支付订单并创建 `reset_price` 周期订单，支付后由后端重置流量。
- **v2board**：依赖订阅 `allow_new_period` 字段 → 调用"流量提前重置"接口（扣减到期时间换流量），即时生效无需支付。

> 说明：前端"续费"按钮复用当前订阅套餐的最近成交周期；若存在未支付订单会先自动取消（含其他套餐的待支付订单）。

## 八、常见问题

**Q：套餐页一片空白 / 提示无套餐？**
- 检查后端是否配置了 `show` 与 `sell` 均为 true 的套餐；v2board 无游客套餐接口，需登录后查看；确认 `api` 配置与 `backend_type` 正确。

**Q：价格显示不对（差 100 倍）？**
- 检查后端金额是否按"分"返回（如 ¥29 应为 `2900`）。若后端返回元，前端展示会放大 100 倍，需后端修正或调整字段。

**Q：套餐介绍显示为原始 JSON / Markdown 源码？**
- `content` 未命中 JSON/HTML 判断时走 marked 渲染属正常；若 JSON 解析失败（如非法 JSON），会回退到 HTML/Markdown 渲染，请检查 JSON 语法。

**Q：为什么有的支付方式列表里没有信用卡？**
- 见上文"StripeCredit 已知限制"。
